© 2026 Fabian Codes HQ. All rights reserved.

Kemist is not affiliated with, endorsed by, or sponsored by any of the data providers below. It only displays registration records that those regulators publish; it cannot tell you whether a physical pack is genuine.

  • NAFDAC — National Agency for Food and Drug Administration and Control. Greenbook registration data, accessed via the Apify platform.
  • Apify — actor orchestration and web data extraction.
  • OpenStreetMap — health-facility places and base map tiles, © contributors.
  • Geoapify — map tile delivery (optional, configured via GEOAPIFY_API_KEY).
  • Leaflet — interactive map library.
  • Google Fonts — Familjen Grotesk and Figtree typefaces.
  • Supabase — database and backend storage.

Additional drug-regulator data sources are planned for the future. Kemist is built to work with any regulator, not only NAFDAC.
